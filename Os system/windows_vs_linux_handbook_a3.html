CH 01

การนำทางและจัดการไดเรกทอรี (Directory & Navigation)

คำสั่งพื้นฐานสำหรับการตรวจสอบตำแหน่งปัจจุบันและการย้ายโฟลเดอร์ภายในระบบไฟล์

การทำงาน Windows (CMD) Linux (Bash) คำอธิบาย
ดูที่อยู่ปัจจุบัน cd pwd แสดง path ปัจจุบันแบบสัมบูรณ์
แสดงไฟล์ในโฟลเดอร์ dir ls แสดงรายชื่อไฟล์และโฟลเดอร์
แสดงแบบละเอียด dir ls -l แสดงสิทธิ์ ขนาด และเวลาแก้ไข
แสดงไฟล์ที่ซ่อนอยู่ dir /a ls -a รวมไฟล์ซ่อน (dotfiles)
เปลี่ยนโฟลเดอร์ cd path cd path ย้ายเข้าไปยังโฟลเดอร์เป้าหมาย
ถอยกลับ / ไป root cd .. | cd \ cd .. | cd / กลับโฟลเดอร์แม่ หรือไป root ไดรฟ์
CH 02

การจัดการไฟล์และโฟลเดอร์ (File & Folder Management)

การสร้าง คัดลอก ย้าย และลบไฟล์หรือโฟลเดอร์อย่างปลอดภัย

การทำงาน Windows (CMD) Linux (Bash) คำอธิบาย
สร้างโฟลเดอร์ใหม่ mkdir dir mkdir dir สร้างโฟลเดอร์ใหม่
สร้างไฟล์เปล่า type nul > f.txt touch f.txt สร้างไฟล์เปล่าหรืออัปเดตเวลา
คัดลอกไฟล์ copy src dst cp src dst คัดลอกไฟล์ต้นทางไปปลายทาง
ย้าย / เปลี่ยนชื่อ move o.txt n.txt mv o.txt n.txt ย้ายหรือเปลี่ยนชื่อไฟล์
ลบไฟล์ del file.txt rm file.txt ลบไฟล์ออกจากระบบ
ลบโฟลเดอร์ทั้งหมด rmdir /s /q folder rm -rf folder ลบโฟลเดอร์และไฟล์ภายในแบบ recursive
CH 03

การดูเนื้อหาและค้นหาภายในไฟล์ (Viewing & Searching)

ตรวจสอบข้อมูลในไฟล์ข้อความ อ่าน log และค้นหาคีย์เวิร์ดด้วย grep/findstr

การทำงาน Windows (CMD) Linux (Bash) คำอธิบาย
แสดงเนื้อหาทั้งหมด type file.txt cat file.txt แสดงข้อความทั้งหมดออกหน้าจอ
เปิดดูทีละหน้า more file.txt less file.txt เปิดดูไฟล์ขนาดใหญ่แบบเลื่อนหน้าได้
ดูบรรทัดแรก (Head) powershell -c "GC" f -Head 10 head -n 10 f.txt แสดง 10 บรรทัดแรกของไฟล์
ดูบรรทัดท้าย (Tail / Log) powershell -c "GC" f -Tail 10 tail -n 10 f.txt แสดง 10 บรรทัดสุดท้าย (ดู log)
ค้นหาข้อความในไฟล์ findstr "key" f.txt grep "key" f.txt ค้นหาคำหรือรูปแบบในไฟล์
CH 04

ข้อมูลระบบและจัดการโพรเซส (System & Processes)

ตรวจสอบสเปกฮาร์ดแวร์ สถานะเน็ตเวิร์ก และการปิดงานโพรเซสที่ค้าง

การทำงาน Windows (CMD) Linux (Bash) คำอธิบาย
ดูข้อมูลระบบ systeminfo uname -a / lscpu ตรวจสอบเวอร์ชัน OS และ CPU
ตรวจสอบ IP Address ipconfig ip a / ifconfig ตั้งค่าและดูสถานะอินเตอร์เฟซเน็ตเวิร์ก
ทดสอบการเชื่อมต่อ ping 8.8.8.8 ping -c 4 8.8.8.8 เช็คแพ็กเกจการรับส่งข้อมูลเครือข่าย
ดูรายการโพรเซส tasklist ps aux แสดงโปรแกรมและโพรเซสที่กำลังทำงาน
ปิดโพรเซส (Kill PID) taskkill /pid 1234 /f kill -9 1234 บังคับปิดโพรเซสด้วยรหัส PID

CH 08

การวินิจฉัยเครือข่ายเชิงลึก (Network Diagnostics & Connectivity Reference)

IP Ping, Routing, Ports, Flush DNS & DHCP

รวบรวมคำสั่งตรวจสอบระบบเครือข่ายอย่างละเอียด ทั้งการเช็คเกตเวย์ แพ็กเกจลอสด์ การเทสต์พอร์ต และการเคลียร์ DNS Cache

หมวดหมู่ / งาน (Task) Windows (CMD / PowerShell) Linux (Ubuntu Terminal) คำอธิบายเพิ่มเติม
เช็ค IP Address ตัวเอง ipconfig ip a (หรือ ifconfig) ตรวจสอบหมายเลขไอพีและการ์ดแลนปัจจุบัน
เช็คการ์ดเน็ตเวิร์กตัวเอง (Localhost) ping 127.0.0.1 ping 127.0.0.1 ทดสอบระบบภายในเครื่องว่า TCP/IP ทำงานปกติไหม
เช็คการเชื่อมต่อเร้าเตอร์ (Gateway) ping 192.168.1.1 ping 192.168.1.1 เช็คสัญญาณเชื่อมต่อไปยังตัวกระจายสัญญาณอินเทอร์เน็ต
เช็คการออกเน็ตภายนอก / DNS ping 8.8.8.8 หรือ ping google.com ping -c 4 8.8.8.8 ทดสอบว่าออกอินเทอร์เน็ตและแปลงชื่อโดเมนได้หรือไม่
เช็คความเสถียร / Packet Loss ping 8.8.8.8 -t ping 8.8.8.8 ปิงต่อเนื่องยาวๆ (กด Ctrl+C เพื่อหยุด)
ดูเส้นทางข้อมูล (Traceroute) tracert 8.8.8.8 traceroute 8.8.8.8 เช็คฮอป (Hops) ทุกโหนดที่สัญญาณวิ่งผ่าน
เช็คพอร์ตเฉพาะ (เปิดอยู่ไหม) Test-NetConnection IP -Port 443 nc -zv IP port ตรวจสอบว่าบริการปลายทาง (เช่น เว็บ, DB) เปิดพอร์ตรับไหม
ล้างแคช DNS (Flush DNS) ipconfig /flushdns sudo systemd-resolve --flush-caches เคลียร์ DNS เก่าเมื่อเว็บไซต์เปลี่ยน IP ใหม่
ขอ IP Address ใหม่จาก DHCP ipconfig /renew sudo dhclient -r && sudo dhclient รีเฟรชขอรับหมายเลขไอพีใหม่จากเร้าเตอร์วงแลน
CH 09

การเชื่อมต่อฮาร์ดดิสก์ (Disk Mounting) และแนวปฏิบัติกรณี "กู้ไฟล์" (Data Recovery)

External Windows Drive on Linux (Ubuntu)

คำสั่งเทียบเคียงและขั้นตอนการเชื่อมต่อฮาร์ดดิสก์วินโดวส์ (NTFS/exFAT) เข้ากับ Linux เพื่อดึงข้อมูลและกู้ไฟล์อย่างปลอดภัย

ขั้นตอน / การทำงาน Windows (CMD / PowerShell) Linux (Ubuntu Terminal) คำอธิบายเพิ่มเติม
1. ค้นหาและดูพาร์ทิชัน diskpart list volume lsblk -f / sudo fdisk -l ตรวจสอบชื่ออุปกรณ์ (เช่น /dev/sdb1)
2. สร้างจุดเชื่อม (Mount Point) จัดการอักษรไดรฟ์ให้อัตโนมัติ sudo mkdir -p /mnt/win_backup สร้างโฟลเดอร์รองรับข้อมูลบน Linux
3. Mount แบบอ่านอย่างเดียว (Read-Only) mountvol E: \\?\Volume{...} sudo mount -o ro /dev/sdb1 /mnt/win_backup สำคัญมาก: ใช้ -o ro เพื่อความปลอดภัย ไม่ให้เขียนทับข้อมูล
4. คัดลอกไฟล์กู้คืน xcopy /s /e E:\ data D:\recovery cp -r /mnt/win_backup/Users/... ~/recovery/ คัดลอกข้อมูลสำคัญไปไว้ที่ไดรฟ์สำรอง
5. ยกเลิกการเชื่อมต่อ (Unmount) mountvol E: /d sudo umount /mnt/win_backup ถอดการเชื่อมต่ออย่างปลอดภัยก่อนดึงสาย
ข้อควรระวังสำคัญกรณี "กู้ไฟล์" (Data Recovery Best Practices)
  • ใช้โหมด Read-Only (-o ro) เสมอ: ป้องกันไม่ให้ Linux พยายามซ่อมแซมหรือเขียนทับไฟล์ระบบ NTFS ที่เสียหาย ซึ่งจะทำให้อัตราการกู้คืนไฟล์ลดลง
  • ปัญหา Fast Startup / Hibernation ของ Windows: หากฮาร์ดดิสก์ลูกนั้นเคยเปิดโหมด Fast Startup ไว้ Linux อาจฟ้อง Unsafe สามารถแก้ไขด้วยคำสั่ง: sudo mount -t ntfs-3g -o ro,remove_hiberfile /dev/sdb1 /mnt/win_backup
  • การจัดการสิทธิ์ไฟล์ (Permissions): หากกู้ไฟล์มาแล้วเปิดดูไม่ได้ ให้ปรับสิทธิ์การเข้าถึงด้วย sudo chmod -R 755 /mnt/win_backup
